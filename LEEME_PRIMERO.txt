================================================================

❌ "Docker no está instalado"
   → Instala Docker Desktop en Windows
   → Asegúrate de habilitar WSL2 integration

❌ "Cannot connect to Docker daemon"
   → Abre Docker Desktop en Windows
   → Espera a que inicie completamente

   → Estás en PowerShell, usa WSL2
   → Abre "Ubuntu" desde el menú de Windows

   → docker logs eco_air_active
   → Verifica memoria asignada
   → Espera 15-20 segundos
